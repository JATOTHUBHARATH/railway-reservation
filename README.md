# Railway Reservation System

A web-based Railway Reservation System developed using Python Flask, MySQL, HTML, CSS, and JavaScript.

## Features
- Search available trains
- View train schedules and fares
- Register passenger details
- Book railway tickets
- Generate booking confirmation
- View and cancel bookings
- Admin dashboard for managing trains and passengers

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Installation and Execution

1. Clone the repository:
   `git clone https://github.com/JATOTHUBHARATH/railway-reservation.git`

2. Install dependencies:
   `pip install -r requirements.txt`

3. Configure your MySQL database credentials using environment variables.

4. Create the database using `schema(railway).sql`.

5. Run the application:
   `python app.py`

6. Open your browser:
   `http://127.0.0.1:5000`
